Case Study — MSP Client Work

Azure AD & Intune Migration

Moved a client's fleet off an aging on-premises Active Directory server and onto Azure AD, enrolling every device into Intune along the way.

Azure AD (Entra ID) Intune Microsoft 365 Device Management

Problem

A client was running an on-premises Active Directory server that was aging, costly to maintain, and tied every device to a single point of failure. Devices needed to move to a cloud identity model without disrupting the people using them day to day.

What I built

I led the transition of company devices off the on-premises AD server into Azure AD, using an Intune enrollment and reset workflow so each machine came back online already joined, policy-compliant, and provisioned with the software the user needed. I coordinated the rollout in batches to minimize downtime and confirmed every device was properly enrolled before moving to the next group.

Architecture

Stack & tools

  • Azure AD (Entra ID) — cloud identity, replacing the on-prem directory
  • Microsoft Intune — device enrollment, compliance policy, and app deployment
  • Microsoft 365 admin center — license and account provisioning

What I learned

Batching the rollout mattered more than I expected — enrolling devices in small groups made it easy to catch policy misconfigurations before they affected everyone, instead of discovering a problem after the whole fleet had already moved. I also learned how much smoother the experience is for end users when the reset-and-enroll workflow is scripted consistently, rather than configured by hand on each machine.
