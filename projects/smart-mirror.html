Case Study — Personal Build

Smart Mirror

A super-slim Raspberry Pi smart mirror — two-way acrylic over a thin display, Pi mounted behind it — running MagicMirror² with modules that pull live status from the homelab.

Problem

I wanted a glanceable display for the things I check every morning — time, weather, calendar — plus a reason to build something physical that ties into the homelab. A smart mirror does both: it's a normal mirror until the display behind it lights up.

What I'm building

The approach is the "super-slim smart mirror" pattern: a sheet of two-way acrylic laid over a thin display panel, with the Raspberry Pi mounted flat behind it so the whole assembly stays shallow enough to hang like a picture frame. The Pi runs MagicMirror², which renders a black-background web page of modules — anything dark disappears behind the acrylic, anything white shows through.

Planned modules:

  • Clock, weather, and calendar — the standard MagicMirror² set
  • Home Assistant status panel (custom, planned) — pulls from the Home Assistant build to show which lights are on, door sensor state, and the like
  • Network+ flashcard rotator (custom, planned) — cycles through study cards for CompTIA Network+ while I get ready in the morning
