Smart Mirror

A super-slim Raspberry Pi smart mirror — two-way acrylic over a thin display, Pi mounted flat behind it — running MagicMirror² with modules that pull live status from the homelab. This one is still on the to-do list; here's the plan.

Planned · not started yet
Raspberry Pi MagicMirror² Two-way acrylic Home Assistant

Why this project

I want a glanceable display for the things I check every morning — time, weather, calendar — and a reason to build something physical that ties into the homelab. A smart mirror does both: it's a normal mirror until the display behind it lights up.

The plan

The approach is the "super-slim smart mirror" pattern: a sheet of two-way acrylic laid over a thin display panel, with the Raspberry Pi mounted flat behind it so the whole assembly stays shallow enough to hang like a picture frame. The Pi runs MagicMirror², which renders a black-background page of modules — anything dark disappears behind the acrylic, anything white shows through.

Planned modules:

  • Clock, weather, and calendar — the standard MagicMirror² set
  • Home Assistant status panel (custom) — pulls from the apartment build to show which lights are on, door sensor state, and the like
  • Network+ flashcard rotator (custom) — cycles through CompTIA Network+ study cards while I get ready in the morning

Build order

  1. Pick the display size, then order the acrylic and frame to match.
  2. Assemble the display + acrylic stack and confirm the mirror effect in the room's actual light.
  3. Install MagicMirror² on the Pi with the default clock/weather/calendar modules.
  4. Write the Home Assistant status module against the HA API.
  5. Write the flashcard module, then mount the whole thing on the wall.
