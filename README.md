## About

This is my personal portfolio site, built from scratch with plain HTML and CSS — no frameworks or build tools. It covers my technical skills, real IT projects I've worked on, and a bit about who I am outside of work.

## Tech Stack

- **HTML / CSS / JavaScript** — vanilla, no frameworks
- **Hosted on:** Netlify (auto-deploys on push to `main`)
- **Domain:** Namecheap
